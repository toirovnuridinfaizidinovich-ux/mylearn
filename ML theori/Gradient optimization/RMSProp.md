## Новый вес = старый вес - скорость обучения * текущий градиент, поделенный на его недавний характерный размер.

Здесь две операции: сначала обновить память, затем изменить вес.

## Обновляем память

G new = βG old + (1 - β)g**2

По-человечески:
Новая память = часть старой памяти + часть квадрата текущего градиента.

 g - текущий градиент: производная ошибки по этому весу.
 G - скользящее среднее квадратов градиентов.
 β - коэффициент памяти, который мы выбираем.

 В отличие от momentum, здесь память не хранит направление: квадрат делает и положительные, и отрицательные градиенты положительными. Мы запоминаем их размер.

 ## Изменяем вес
 
 w new = w old - n*(g/(np.sqrt(G new) + ε))

 w - weight model
 n - speed learning
 np.sqrt(G new) - накопленная оценка размера градиентов
 ε - маленькая добавка для защиты от деления на 0

 То есть обычное обновление «вычесть скорость × градиент» дополнительно делится на накопленный масштаб. Для каждого веса этот масштаб свой.

## Один простой пример

Предположим, история уже накоплена:

text
Текущий вес:       w = 5
Текущий градиент:  g = 2
Старая память:     G = 4

Выбрали:
коэффициент памяти  β = 0.9
скорость обучения  η = 0.1

Сначала память:
G new = 0.9 * 4 + 0.1*2**2 = 4

Затем делитель:
np.sqrt(4) = 2

Делим текущий градиент:
g/np.sqrt(G) = 2/2 = 1

Обновляем вес, пренебрегая крошечным ε.
w new = 5 - 0.1*1 = 4.9

## Что запомнить
У momentum память участвует в самом движении:

«Продолжай учитывать прошлые направления».

У RMSProp память используется как делитель:

«Прежде чем использовать текущий градиент, сравни его размер с привычным для этого веса».

То есть RMSProp — не «история минус поправка», как в нашей записи momentum. Это «текущий градиент, масштабированный с помощью истории».

## Логика по шагам

Вычисляем 𝑔: насколько ошибка меняется при небольшом изменении этого веса.
Обновляем 𝐺: запоминаем недавнюю силу градиентов через их квадраты.
Берём 𝐺: возвращаемся к обычному масштабу градиентов.
Делим 𝑔 на 𝐺 : получаем относительную силу текущего градиента.
Умножаем на η: задаём итоговый размер движения.
Вычитаем из веса: вес меняется, потому что мы делаем шаг против наклона ошибки.
