## Диагональный метод Левенберг_Марквардт: суть
Это попытка использовать не только наклон ошибки, но и её кривизну — то, насколько быстро меняется наклон. Полный метод Ньютона делает это через матрицу Гессе, но для миллионов весов она слишком дорогая. Поэтому здесь гессиан упрощают: оставляют только главную диагональ и игнорируют связи между разными весами.

Коротко:
Обычный градиентный спуск смотрит на наклон. Диагональный Левенберг–Марквардт смотрит на наклон и на локальную кривизну по каждому весу отдельно.

## Что такое гессиан
Для одного веса 𝑤𝑗 у нас уже есть:
gj = ∂w / ∂L
Это первая производная: насколько ошибка меняется при небольшом изменении веса.

Вторая производная:
hjj = ∂**2L / ∂wj**2

Она показывает, как меняется сам наклон при изменении веса.

Простая аналогия:
g - «насколько крутой склон сейчас»
hjj - «насколько быстро склон становится круче или положе»

## Полный метод Ньютона
Полная формула Ньютона:
w new = w old - nH**-1g

Здесь:
g - вектор градиентов
H - матрица Гессе
H**-1 - обратная матрица Гессе

Матрица Гессе содержит вторые переменные по всем парам весов:
Hij = ∂**2L / ∂wi∂wj

То есть она учитывает, как изменение одного веса влияет на наклон ошибки по другому весу.

## Почему полный Ньютон дорогой
Если весов 𝑛, то матрица Гессе имеет размер 𝑛×𝑛.

Например:
100.000 весов - матрица 100.000*100.000

Это уже около 10 миллиардов элементов. А ещё её нужно обращать. Поэтому для больших нейросетей полный Ньютон практически не используют.

## Что значит «диагональный»
Мы оставляем только вторые производные каждого веса по самому себе:
hjj = ∂**2L / ∂wj**2

А все смешанные производные считаем нулями:
hij = 0 при i!=j

Получается диагональная матрица:
D = ( 
    h11 0 ... 0
    0 h22 ... 0
    0 0 h33 ... 0
    ... ... ... ...
    0 0 0 ... hnm
)

Её обратная матрица очень простая: нужно лишь разделить единицу на каждый диагональный элемент:

D**-1 = (
    1/h11 0 ... 0
    0 1/h22 ... 0
    0 0 1/h33 ... 0
    ... ... ... ...
    0 0 0 ... 1/hnm
)

Поэтому вместо обращения огромной матрицы достаточно для каждого веса вычислить 1/ℎ𝑗𝑗.

## Формула метода
Для каждого веса отдельно:
wj new = wj old - n*(gj / (hjj + μ))

Где:
wj - конкретный вес
gj - Первая производная ошибки по этому весу
hjj - Вторая производная ошибка по этмоу веса 
μ - маленькая положительная добавка
n - коэффициент шага

По-человечески:
Новый вес = старый вес - базовый шаг * текущий градиент, поделенный на локальную кривизну плюс защита.

## Что делает 𝜇
𝜇 выполняет две роли:
1) Защита от деления на 0
2) Не дает шагу стать слишком большим, когда кривизна мала.

Если hjj близко к нулю, то без 𝜇 получилось бы:
gj/hjj
А это может быть огромным числом. С добавкой:
gj / (hjj + 𝜇)
знаменатель не становится нулевым, и шаг остается ограниченным.

То есть 𝜇 - это не "скорость обучения" в обычном смысле. Это страховка и регулятор: чем больше 𝜇, тем сильнее метод приближается к обычному градиентному спуску.

## Простой пример
Пусть для одного веса:
text
Текущий вес:              w = 5
Текущий градиент:         g = 2
Вторая производная:       h = 4
Добавка:                  μ = 1
Базовый коэффициент:      η = 1

Считаем: 
g / (h + μ) = 2 / (4+1) = 0.4

Обновляем вес:
w new = 5 - 1*0.4 = 4.6

Теперь представь, что кривизна маленькая:
h = 0.1
μ = 1
g = 2

Тогда:
2 / (0.1 + 1) = 1.82
w new = 5 - 1.82 = 3.18

Шаг больше, потому что поверхность в этой точке почти плоская: наклон меняется слабо, и метод позволяет пройти дальше.

А если кривизна большая:
h = 100
μ = 1
g = 2

Тогда:
2/100+1 = 0.02
w new = 5 - 0.02 = 4.98

Шаг маленький: поверхность быстро меняет наклон, поэтому рискованно делать большой прыжок.

RMSProp сравнивает градиент с его прошлой силой.
Диагональный Левенберг–Марквардт делит градиент на текущую кривизну.

В RMSProp знаменатель — статистика прошлых градиентов. Здесь знаменатель — вторая производная ошибки в текущей точке.

## Что запомнить
Градиент g говорит, куда и насколько сильно склон ведёт вниз.

Вторая производная hjj говорит, насколько быстро меняется этот склон.

Полный Ньютон учитывает кривизну и связи между всеми весами, но слишком дорог.

Диагональный метод оставляет только кривизну каждого веса по отдельности.

Деление на hjj+μ уменьшает шаг там, где поверхность сильно изгибается.

μ защищает от деления на ноль и ограничивает шаг при почти плоской поверхности.

Главная мысль:

Это не «история минус поправка», как в momentum. Это попытка сделать шаг умнее: не только по наклону, но и по тому, насколько быстро наклон меняется.
